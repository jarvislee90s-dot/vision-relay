一条透明的本地中转，模型和上游都无感。

① 你正常贴图在 Claude Code 等工具里粘贴截图提问，什么都不用改。
→
② 视觉模型替它"看"vision-relay 拦下图片，请专门的看图模型转成文字描述。
→
③ 文本模型收到描述上游只见到文字——纯文本模型就此"会看图"。

三分钟上手

一个 key，三步开工。

下载并安装

按平台下载安装包，像普通应用一样装好、打开。不需要 Python 环境。

填一个"看图"模型的 key

首次向导里填入视觉模型（如 qwen-vl-max、mimo、豆包视觉…）的地址与 key——唯一必填项。

开路由，贴图开测

打开路由开关，回到 Claude Code 贴张截图问"这是什么"——看到流畅的文字描述就成功了。

隐私与安全

  • 🔐 密钥只存本机：API key 保存在你电脑的配置文件里（权限 0600），日志永不记录密钥。
  • 🏠 记录只留在本机：识图记录默认保留 7 天自动清理，也可关闭；不上传任何服务器。
  • 🔌 只听本机回环：服务只监听 127.0.0.1，不对局域网 / 外网开放。
