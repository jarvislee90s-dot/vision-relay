## 🔧 修了什么

**Python 3.10：回落直连崩溃修复（pip 安装用户必更）**

v1.0.0 的「工具端口死时回落直连」功能里有一处裸 `import tomllib`——tomllib 是 Python 3.11 才进标准库的模块，而 vision-relay 声明支持 3.10 起步。结果是：**Python 3.10 环境下**，当你用 cc-switch 管理 codex 供应商、且它的工具端口恰好离线时，回落解析会当场报错。本版改为守卫导入 + 正则兜底，3.10 上同样可用。

说明两点：

- 代理本身**不会崩**（fail-open 兜底一直在），受影响的只是那一类请求的降级方式；
- GUI 安装包（Windows / macOS / Linux）内嵌的是 Python 3.12 冻结核心，**不受此 bug 影响**——这类用户更新与否随意。

## 🏗 内部：两大子系统模块化重构（零行为变更）

配置接线（wiring）与 CLI/动词层按职责拆成了小模块，三个大文件收敛为组装层门面。**你能碰到的每一个接口都没变**：命令、输出、退出码、GUI 行为、配置文件格式全部原样；回归靠 757 个测试钉死（拆分前 561 个，且既有断言一行未改）。详见 [REFACTOR_NOTES.md](https://github.com/jarvislee90s-dot/vision-relay/blob/main/REFACTOR_NOTES.md)。

其余内部改进：发布正文人工文案优先（重跑发布工作流不再盖掉图文公告）、CI 矩阵恢复全绿（3 系统 × Python 3.10–3.13）。

## ⬇️ 下载安装包

装完即用，**不需要 Python 环境**（核心已内嵌）。

| 平台 | 安装包 | 说明 |
|---|---|---|
| 🪟 Windows 10/11 · x64 | `vision-relay-1.0.1-win-x64-setup.exe` | 常规安装向导 |
| 🍎 macOS · Apple Silicon | `vision-relay-1.0.1-macos-arm64.dmg` | 拖入「应用程序」即可；Intel Mac 暂不支持 |
| 🐧 Linux · x64 | `vision-relay-1.0.1-linux-x64.AppImage` / `.deb` | AppImage 免安装，deb 适用于 Debian/Ubuntu 系 |

完整性校验：把 [SHA256SUMS.txt](https://github.com/jarvislee90s-dot/vision-relay/releases/download/v1.0.1/SHA256SUMS.txt) 下载到与安装包相同的目录，在下载目录内执行 `shasum -a 256 -c SHA256SUMS.txt`（Windows 可用 `certutil -hashfile <文件> SHA256` 逐个比对）。

> 无界面 / 服务器场景也可以走命令行：`pip install vision-relay`（Python 3.10–3.13），用法见 [README](https://github.com/jarvislee90s-dot/vision-relay/blob/main/README.zh.md)。**本版本起 Python 3.10 全功能可用。**

## 📝 已知限制（同 v1.0.0）

- macOS 包为 Apple Silicon 原生；Intel Mac 暂不支持（原生 universal 包随后续版本提供）。
- qwen-code 的接线在会话启动时加载：已开的 qwen 会话需重启后才会走代理。
- 两个应用同时想改同一份工具配置时，vision-relay 会在总览页提示并可一键抢回——不建议让多工具混改。
