## 👀 这是什么？

你在 Claude Code 里贴一张架构图，它却回答"我看不到图片"——因为 underlying 模型是纯文本的。vision-relay 在本机架一条**透明中转**：

```
① 你照常贴图提问
        ↓
② vision-relay 拦下图片，请专门的"看图"模型转成文字描述
        ↓
③ 文字描述交给你的文本模型 —— 上游只见文本，模型无感
```

不需要给工具装任何 skill / 插件，不需要改任何使用习惯；纯文本模型从此"会看图"。

## ✨ 你现在可以（v1.0.0 全部能力）

- **贴图即用，模型无感** —— 四大 AI 编程工具（Claude Code / Codex / Qwen Code / zcode）开箱接管，图片自动转述、文本照常转发，模型自己都不知道发生了什么。
- **谁会看图，实测说了算** —— 模型能力矩阵对每个模型发真实请求探测：谁接受图片、谁拒图，逐行给出 ✓/✗ 实测结论，不再靠猜、不浪费 token。
- **每次看图都留底稿** —— 发给看图模型的提示词、它的原始回答、实际注入对话的文本，三段明细随时可查，转述质量可审计。
- **自动对账、自动修复** —— 接线被别的工具改了？自动抢回。上游供应商变了？自动吸收。能自己修的绝不打扰你，修不了的才列进"需要你"。
- **看图模型挂了也不怕** —— 任何故障自动降级为文字提示，请求绝不卡死：不会因为你发了一张图就中断手头工作。
- **图形控制台，五个页签管完** —— 总览、模型能力、识图记录、事件日志、设置；首次打开有两步向导，平时系统托盘常驻，关了窗口服务照跑。
- **和 CC Switch / Codex++ 和平共处** —— 两层路由实测可用，请求链路在总览页看得一清二楚。

## ⬇️ 下载安装包

装完即用，**不需要 Python 环境**（核心已内嵌）。

| 平台 | 安装包 | 说明 |
|---|---|---|
| 🪟 Windows 10/11 · x64 | `vision-relay-1.0.0-win-x64-setup.exe` | 常规安装向导 |
| 🍎 macOS · Apple Silicon | `vision-relay-1.0.0-macos-arm64.dmg` | 拖入「应用程序」即可；Intel Mac 暂不支持 |
| 🐧 Linux · x64 | `vision-relay-1.0.0-linux-x64.AppImage` / `.deb` | AppImage 免安装，deb 适用于 Debian/Ubuntu 系 |

完整性校验：把 [SHA256SUMS.txt](https://github.com/jarvislee90s-dot/vision-relay/releases/download/v1.0.0/SHA256SUMS.txt) 下载到与安装包相同的目录，在下载目录内执行 `shasum -a 256 -c SHA256SUMS.txt`（Windows 可用 `certutil -hashfile <文件> SHA256` 逐个比对）。

> 无界面 / 服务器场景也可以走命令行：`pip install vision-relay`，用法见 [README](https://github.com/jarvislee90s-dot/vision-relay/blob/main/README.zh.md)。

## 🚀 三分钟上手

1. **下载并安装**，像打开普通应用一样启动 vision-relay（macOS 启动台 / Windows 开始菜单 / Linux 应用列表）。
2. **首次向导填一个"看图"模型的 key**（如 qwen-vl-max、mimo、豆包视觉……）——这是唯一必填项；第二步过目一下模型能力清单即可完成。
3. **打开总览页的路由开关**，回到 Claude Code 贴张截图问"这是什么"——看到流畅的文字描述就成功了 🎉

想看每个页签都能点什么？[GUI 逐页使用手册](https://github.com/jarvislee90s-dot/vision-relay/blob/main/README.zh.md#各页签详解)（总览 / 模型能力 / 识图记录 / 事件日志 / 设置 + 进阶功能）。

## 🔐 隐私与安全

- **密钥只存本机**：API key 保存在本机配置文件（权限 0600），日志永不记录密钥。
- **记录只留在本机**：识图记录默认保留 7 天自动清理，可关闭；不上传任何服务器。
- **只听本机回环**：服务只监听 `127.0.0.1`，不对局域网 / 外网开放。

## 📝 已知限制（首版）

- macOS 包为 Apple Silicon 原生；Intel Mac 暂不支持（原生 universal 包随后续版本提供）。
- qwen-code 的接线在会话启动时加载：已开的 qwen 会话需重启后才会走代理。
- 两个应用同时想改同一份工具配置时，vision-relay 会在总览页提示并可一键抢回——不建议让多工具混改。
